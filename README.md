# Minecraft Bot Panel

Autorski panel do zarządzania botami Minecraft przez przeglądarkę.

## Funkcje
- Wpisz IP, port, wersję, liczbę botów
- Start / Stop botów
- Wysyłanie wiadomości na czat przez wszystkie boty
- Wykonywanie komend
- Lista botów online/offline
- Auto-reconnect po rozłączeniu

## Uruchomienie
```bash
npm install
npm start
